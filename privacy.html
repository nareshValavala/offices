Privacy Policy: Studio Analytics (personal)

Last updated: 29 October 2026

Who this is

Studio Analytics (personal) is a private tool run by Naresh Valavala for his own YouTube channels. It is not offered to the public and has no other users.

What it accesses

With the channel owner's own permission, it reads data about the owner's own YouTube channels through the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API, using read-only access. This includes channel and video details and performance figures such as views, watch time, audience retention, traffic sources and impressions.

How the data is used

The data is shown in a private dashboard on the owner's own computer so that he can see how his videos perform and decide what to make next.

Storage and sharing

The data is stored only on the owner's computer. It is not sold, shared with, or transferred to any third party, and it is not used for advertising. Access credentials are stored only on that computer and can be revoked at any time.

Google API Services User Data Policy

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account permissions page at myaccount.google.com/permissions.
